# Serverless Function Execution Platform

[GitHub Repository](https://github.com/Bhavesh2k4/Lambda_Serverless)

A comprehensive serverless compute platform that eliminates infrastructure management complexity while providing powerful function execution capabilities. This project demonstrates the implementation of a production-ready serverless platform using modern web technologies and multiple execution engines.

## What This Project Does

This platform allows developers to upload and execute code functions without managing any server infrastructure. Think of it as your own mini AWS Lambda service - users can simply upload Python or JavaScript code, and the platform handles everything from storage to execution.

### Core Functionality

**Function Upload & Management**
- Upload Python or JavaScript functions through a web interface
- Functions are securely stored in AWS S3 cloud storage
- Function metadata (name, language, settings) stored in PostgreSQL database
- Clean dashboard to view and manage all your functions

**Two Execution Modes**
- **Docker Containers**: Traditional containerization for reliable, isolated execution
- **Nanos Unikernels**: Ultra-lightweight virtual machines for faster startup and better performance
- Both modes accessible through simple HTTP API calls

**User Authentication**
- Secure user accounts with email/password registration
- OAuth login with Google and GitHub
- Email verification and password reset functionality
- Each user has their own isolated function space

## How It Works

1. **Sign Up**: Create an account using email or OAuth providers
2. **Upload Code**: Write your function in Python or JavaScript and upload it
3. **Configure**: Set memory limits, timeout values, and other execution parameters
4. **Execute**: Call your function via HTTP with parameters
5. **Monitor**: View execution results, performance metrics, and error logs

### Example Usage

Once you upload a function, you can call it like this:
```
GET /api/function/your-user-id/calculator/docker?a=5&b=10
GET /api/function/your-user-id/calculator/nanos?a=5&b=10
```

The platform executes your code and returns the results instantly.

## Technical Implementation

**Frontend**: Built with Next.js and TypeScript for a responsive web interface

**Backend**: Node.js API handling authentication, file management, and function execution

**Database**: PostgreSQL with Prisma ORM for storing user data and function metadata

**Storage**: AWS S3 for secure, scalable function code storage

**Execution**: Custom-built execution engines using Docker and Nanos technologies

**Security**: Multi-layer authentication with NextAuth and secure function isolation

## Why This Matters

- **No Infrastructure Hassle**: Developers can focus on writing code, not managing servers
